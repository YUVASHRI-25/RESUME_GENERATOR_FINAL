# Lorna Modern Template

This is the Lorna Modern resume template - a clean, two-column layout with a professional gray and white color scheme.

## Files

- `Template.jsx` - The React component that renders the resume
- `template.css` - Locked styles for pixel-perfect layout
- `schema.js` - Data transformation mapping from standard resume format to template format
- `preview.png` - Preview image for template selection (place in `public/templates/lorna-modern/preview.png`)

## Preview Image

**Important:** You need to add the `preview.png` file manually:

1. Save the template preview image as `preview.png`
2. Place it in: `frontend/public/templates/lorna-modern/preview.png`

The preview image should be a screenshot or rendered version of the template for display on the template selection page.

## Usage

The template is automatically registered in the template registry and will appear on the template selection page once the preview image is added.
